# Gifts Presenter — Sample Demo Project

Pranam and welcome. This folder contains a pre-synchronized devotional song package ready for testing and demonstration in Gifts Presenter.

---

## Package Contents

`Gifts-Demo-Bhajan.zip` contains 2 pre-synchronized bhajans with complete devotional recordings, timing data, and stage visual styling:

1. **गोविंद — Prem Rawat**
   - **Duration**: 4 minutes 54 seconds (294.8s).
   - **Synced Verses**: 50 pre-calibrated lyric lines with instrumental breaks.
   - **Audio Track**: Full master recording (`audio.mp3`).
   - **Opening Verse**: *हे राम गोविंद हरे मुरारे*

2. **धागा — Prem Rawat**
   - **Duration**: 5 minutes 06 seconds (306.8s).
   - **Synced Verses**: 36 pre-calibrated lyric lines with instrumental passages.
   - **Audio Track**: Full master recording (`audio.mp3`).

## 3-Step Quick Start Guide

### Step 1: Open Gifts Presenter
Launch Gifts Presenter on your computer.

### Step 2: Import the Demo Package
You can import the demo using either of these two methods:
- **Method A (Direct Button)**: In the left Song Library panel, click the **Load Demo** button (with the download icon).
- **Method B (File Picker)**: Click **Project** in the top navigation bar, select **Import Project (.gifts.zip)** (or click **Import ZIP** in the Song Library), navigate to this folder, and select `Gifts-Demo-Bhajan.zip`.

### Step 3: Test Stage Presentation
1. Switch to **Stage Console** mode in the top navigation bar.
2. Click **Start Presentation** to activate the audience projector output.
3. Press **Spacebar** to begin playback. Notice how the Sacred Lotus music animation displays during instrumental interludes, transitions smoothly between lyric slides, and holds cleanly on screen when paused for discourse.
